# Site Jumper

Расширение для Chromium-браузеров и Firefox: на странице фильма или сериала Кинопоиска между обложкой и трейлером появляется плеер зеркала `kinopoisk.me` размером с трейлер.

## Установка (вручную)
1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. «Загрузить распакованное» → выберите эту папку.

## Использование
- Откройте страницу вида `kinopoisk.ru/film/…` или `kinopoisk.ru/series/…`.
- Под обложкой нажмите «▶ Смотреть здесь».
- Перед первой загрузкой расширение спросит подтверждение (сторонний сайт, возможна реклама); можно отключить вопрос.
- Полноэкранный режим — кнопка в самом плеере.

## Как это устроено
Кинопоиск запрещает чужие фреймы через CSP, поэтому расширение снимает заголовок `Content-Security-Policy` у страниц `kinopoisk.ru` (`rules.json`, права `declarativeNetRequest` и доступ к `kinopoisk.ru`). Это ослабляет защиту страниц Кинопоиска; чтобы отключить, уберите правило из `manifest.json` (плеер при этом перестанет загружаться).

## Свои правила
Правила лежат в `rules.js` (`SITE_RULES`). Для нового сайта добавьте правило туда и адрес в `matches` в `manifest.json`.

## Тесты
```
node --test rules.test.js
```

## Публикация
Расширения для доступа к сторонним зеркалам могут быть отклонены Chrome Web Store, поэтому основной способ установки — ручной.
