# Site Jumper

Расширение для Chromium-браузеров и Firefox: на странице фильма или сериала Кинопоиска над заголовком фильма появляется блок с плеером 582×280 (на экране 1920 px). Список плееров берётся с того же API Kinobox, что использует зеркало, а выбор плеера и озвучки — своя панель над видео.

## Установка (вручную)
**Chrome / Edge:** `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка проекта.

**Firefox (115+):** `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → `manifest.json`.

## Использование
- Откройте страницу вида `kinopoisk.ru/film/…` или `kinopoisk.ru/series/…`.
- В блоке над заголовком нажмите «▶ Смотреть здесь».
- Перед первой загрузкой расширение спросит подтверждение (плееры сторонние, возможна реклама); можно отключить вопрос.
- Над видео два списка: плеер («1 :: Дублированный (BDRip)») и озвучка выбранного плеера. Последний выбранный плеер запоминается.
- Полноэкранный режим — кнопка в самом плеере.
- Если озвучки у плеера ведут на один адрес (Veoveo, Collaps), второй список скрыт: озвучка выбирается внутри плеера.
- У некоторых фильмов API не отдаёт ссылки плееров (Alloha и другие) — тогда блок покажет «Плееры не найдены».

## Как это устроено
Список плееров запрашивает `background.js` (`https://fbphdplay.top/api/players?kinopoisk=ID`, адрес — `PLAYERS_API` в `rules.js` и `host_permissions`). Кинопоиск запрещает чужие фреймы через CSP, поэтому расширение снимает заголовок `Content-Security-Policy` у страниц `kinopoisk.ru` (`rules.json`, права `declarativeNetRequest` и доступ к `kinopoisk.ru`). Плееру отправляется только домен Кинопоиска в Referer (`referrerPolicy: origin`): без него Alloha отвечает «Ошибка!». Это ослабляет защиту страниц Кинопоиска; чтобы отключить, уберите правило из `manifest.json` (плеер при этом перестанет загружаться).

## Блок на странице
Блок вставляется перед обёрткой заголовка `h1[itemprop="name"]`, ширина — колонка заголовка, но не больше 582 px, пропорции 582:280. Если Кинопоиск поменяет вёрстку, поправьте `findTitle` в `content.js`.

## История версий
- **0.7.0** — плеер над заголовком фильма, 582×280; Referer `origin` (чинит Alloha).
- **0.6.0** — список плееров из API Kinobox вместо зеркала, панель выбора плеера и озвучки.
- **0.5.0** — плеер между обложкой и трейлером, без плавающей кнопки.
- **0.4.0** — встроенный плеер зеркала на странице фильма.
- **0.3.x** — перенос страницы на зеркало одной кнопкой.

## Публикация
Расширения для доступа к сторонним зеркалам могут быть отклонены Chrome Web Store, поэтому основной способ установки — ручной.
