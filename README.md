# Site Jumper

Расширение для Chromium-браузеров и Firefox: на странице фильма или сериала Кинопоиска между обложкой и трейлером появляется блок с плеером размером с трейлер. Список плееров берётся с того же API Kinobox, что использует зеркало, а выбор плеера и озвучки — своя панель над видео.

## Установка (вручную)
1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. «Загрузить распакованное» → выберите эту папку.

## Использование
- Откройте страницу вида `kinopoisk.ru/film/…` или `kinopoisk.ru/series/…`.
- Под обложкой нажмите «▶ Смотреть здесь».
- Перед первой загрузкой расширение спросит подтверждение (плееры сторонние, возможна реклама); можно отключить вопрос.
- Над видео два списка: плеер («1 :: Дублированный (BDRip)») и озвучка выбранного плеера. Последний выбранный плеер запоминается.
- Полноэкранный режим — кнопка в самом плеере.

## Как это устроено
Список плееров запрашивает `background.js` (`https://fbphdplay.top/api/players?kinopoisk=ID`, адрес — `PLAYERS_API` в `rules.js` и `host_permissions`). Кинопоиск запрещает чужие фреймы через CSP, поэтому расширение снимает заголовок `Content-Security-Policy` у страниц `kinopoisk.ru` (`rules.json`, права `declarativeNetRequest` и доступ к `kinopoisk.ru`). Это ослабляет защиту страниц Кинопоиска; чтобы отключить, уберите правило из `manifest.json` (плеер при этом перестанет загружаться).

## Тесты
```
node --test rules.test.js
```

## Публикация
Расширения для доступа к сторонним зеркалам могут быть отклонены Chrome Web Store, поэтому основной способ установки — ручной.
