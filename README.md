# Site Jumper

Расширение для Chromium-браузеров: на странице фильма или сериала Кинопоиска добавляет кнопку «▶ Смотреть», которая переносит страницу на `kinopoisk.me` (путь и параметры сохраняются).

## Установка (вручную)
1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. «Загрузить распакованное» → выберите эту папку.

## Использование
- Откройте страницу вида `kinopoisk.ru/film/…` или `kinopoisk.ru/series/…`.
- Нажмите оранжевую кнопку внизу справа или иконку расширения.
- Перед первым переходом браузер спросит подтверждение (сторонний сайт, возможна реклама); можно отключить вопрос.

## Свои правила
Правила лежат в `rules.js` (`SITE_RULES`). Для нового сайта добавьте правило туда и адрес в `matches` в `manifest.json`.

## Тесты
```
node --test rules.test.js
```

## Публикация
Расширения для доступа к сторонним зеркалам могут быть отклонены Chrome Web Store, поэтому основной способ установки — ручной.

## Плеер прямо на Кинопоиске (0.4.0)
На странице фильма/сериала перед блоком «О фильме» появляется кнопка «Смотреть здесь»; по клику (после подтверждения) загружается зеркало во фрейме.
Кинопоиск запрещает чужие фреймы через CSP, поэтому расширение снимает заголовок `Content-Security-Policy` у страниц `kinopoisk.ru` (`rules.json`, права `declarativeNetRequest` и доступ к `kinopoisk.ru`). Это ослабляет защиту страниц Кинопоиска; чтобы отключить, уберите правило из `manifest.json`.
