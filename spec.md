# Site Jumper — ТЗ

## Цель
Одним кликом переносить текущую страницу Кинопоиска на зеркало: `kinopoisk.ru` → `kinopoisk.me`. Зеркало само редиректит на страницу с плеерами.

## Решения (по итогам вопросов)
| Вопрос | Решение |
|---|---|
| Как открывать | В той же вкладке |
| Какие сайты | Только Кинопоиск (`kinopoisk.ru` → `kinopoisk.me`), правила в одном месте |
| Кнопка на сайте | Плавающая, внизу справа |
| Где показывать кнопку | Только на страницах фильмов и сериалов (`/film/…`, `/series/…`) |
| Предупреждение | Подтверждение перед переходом на сторонний сайт |
| Распространение | Chrome Web Store не гарантирован (риск отклонения), основной путь — ручная установка |

## Функции
1. **Преобразование URL**: меняется только домен (включая `www.`), путь, query и hash сохраняются.
2. **Кнопка на странице**: показывается только на страницах фильма/сериала, скрывается на остальных (главная, поиск, профиль).
3. **Иконка расширения**: на странице фильма/сериала переносит вкладку; на остальных страницах ничего не делает (или показывает подсказку).
4. **Подтверждение**: перед первым переходом диалог «Откроется сторонний сайт (kinopoisk.me), возможна реклама. Продолжить?». Вариант «Больше не спрашивать» хранится в `chrome.storage`.
5. **SPA-навигация**: кнопка обновляется при смене адреса без перезагрузки страницы.

## Подводные камни
- **Кинопоиск — SPA**: адрес меняется без перезагрузки, нужно отслеживать навигацию (сейчас опрос раз в 500 мс; лучше `navigation`-событие/`MutationObserver`).
- **Вёрстка может измениться**: поэтому кнопка плавающая и не привязана к элементам сайта.
- **Трекинг-параметры** (`utm_referrer`, `socialAlias`): по умолчанию сохраняются как есть; решение «чистить или нет» — открытый вопрос.
- **Стороннее зеркало**: реклама, возможные риски безопасности; отсюда предупреждение.
- **Chrome Web Store**: расширения для доступа к пиратским зеркалам могут отклонить; запасной путь — установка из папки/архива.
- **Домены меняются**: зеркала блокируют и переезжают; правила должны быть вынесены в одно место, а лучше в настройки.
- **Права**: минимально необходимые (`tabs` нужен только для обновления вкладки; можно заменить на `activeTab`).

## Три причины, почему это может не сработать
1. **Зеркало перестанет работать или сменит домен** — кнопка поведёт в пустоту. Нужны настройки правил, а не зашитый домен.
2. **Кинопоиск поменяет структуру URL или вёрстку** — фильтр `/film/`, `/series/` перестанет совпадать, кнопка пропадёт. Проверка путей должна быть в одном месте и покрыта тестами.
3. **Магазин расширений отклонит публикацию, либо браузер ограничит MV3 service worker/права** — тогда останется только ручная установка; это надо принять заранее и описать в README.
